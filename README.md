# NerdUninstaller

Geek Uninstaller 風の Android 向けアンインストーラーです。
[Shizuku](https://shizuku.rikka.app/) を使うと、root 化しなくても、普通は adb を使わないと消せないプリインストールアプリを削除できます。

- 対応: Android 13 以降（非 root 端末）
- 技術: Kotlin / Jetpack Compose / Material 3 / Shizuku API

## 機能

- アプリ一覧（アイコン・名前・パッケージ名・サイズ・更新日）
- 検索（アプリ名・パッケージ名）、並べ替え（名前 / サイズ / インストール日 / 更新日）
- フィルタ: ユーザー / システム / 無効化中 / 削除済み / すべて
- 長押しで複数選択して一括アンインストール
- 詳細画面: 起動、アプリ情報、ストアを開く、パッケージ名のコピー
- 標準のアンインストール画面の呼び出し（Shizuku なしで使えます）
- **Shizuku を使う機能**
  - システムアプリの強制アンインストール（`pm uninstall --user 0`、データを残す `-k` も選べます）
  - 無効化 / 有効化（`pm disable-user` / `pm enable`）
  - 削除したシステムアプリの復元（`cmd package install-existing`）
  - 強制停止
  - 「使用状況へのアクセス」をワンタップで許可（アプリサイズ表示用）
- システムアプリごとに削除の危険度（削除OK / 注意 / 危険 / 不明）を表示し、「危険」のアプリを消すときは確認を追加で求めます

## インストール

[Releases の `latest`](../../releases/tag/latest) から `NerdUninstaller.apk` をダウンロードしてインストールしてください。
`main` に push されるたびに GitHub Actions がビルドして、ここを更新します。

> 署名にはリポジトリに含まれている共有デバッグ鍵（`keystore/debug.keystore`）を使っています。
> 毎回同じ鍵で署名されるので、新しいビルドをそのまま上書きインストールできます。

## Shizuku のセットアップ（root なし・Android 13 以降）

1. Google Play または [公式サイト](https://shizuku.rikka.app/download/) から Shizuku をインストールします
2. 端末の「開発者向けオプション」を有効にして、「ワイヤレスデバッグ」をオンにします
3. Shizuku アプリで「ワイヤレスデバッグ経由で起動」→「ペアリング」を選び、表示されるペアコードを入力します
4. Shizuku を起動します
5. NerdUninstaller を開き、バナーの「許可する」を押します

※ 端末を再起動すると Shizuku は止まるので、そのたびに手順 4（起動）をやり直してください。

## 注意事項

- `pm uninstall --user 0` は、アプリを**現在のユーザーから**削除する操作です。APK 本体はシステム領域に残るので、ストレージはあまり空きません。工場出荷時リセットをすると元に戻ります。
- 削除したシステムアプリは「削除済み」タブ、またはメニューの「パッケージ名を指定して復元」から戻せます。
- 危険度の表示はあくまで目安です。よくわからないアプリは、削除せずにまず「無効化」で様子を見ることをおすすめします。
- 「危険」と表示されたアプリを削除すると、端末が起動しなくなる（ブートループ）おそれがあります。

## ビルド

```bash
./gradlew assembleDebug
```

JDK 17 と Android SDK（compileSdk 35）が必要です。
